# 03 · 混合键合（Hybrid Bonding）与 2.5D / 3D 区别

> 一句话：混合键合让两块芯片**铜直接对铜、无缝压接**，比传统的“凸点+底部填充”更密、更精细，是 2.5D/3D 封装迈向高密互连的关键。

## 1. 传统做法 vs 混合键合

**传统做法（Microbump，微凸点）**
- 芯片之间用**焊球/铜柱（solder bump / copper pillar）+ 底部填充（underfill）**连接。
- 优点：工艺成熟。缺点：凸点间距有限（~40 μm 以上），越密越难，且焊料带来寄生效应。

**混合键合（Hybrid Bonding）**
- 表面同时有**铜焊盘 + 介质（SiO₂）**。通过 CMP 把两者磨平，然后**铜对铜扩散键合 + 介质对介质键合**，一层层往上叠。
- 好处：**间距小到 <10 μm**，密度极高，电性能更好，也不怕焊料桥接。

| 对比 | 微凸点 | 混合键合 |
| :--- | :--- | :--- |
| 互连间距 | ≥ 40 μm | < 10 μm |
| 互连密度 | 低 | 高 |
| 电性能 | 有焊料寄生 | 纯铜，更优 |
| 工艺难度 | 成熟 | 高（需超高平整度） |

## 2. 2.5D vs 3D —— 这是关键的区分点

### 2.5D 封装（Interposer 中介层）
```
          裸片A      裸片B      裸片C
            │          │          │
        ────┼──────────┼──────────┼────  ← 硅中介层（Interposer，上面走 RDL/TSV）
            └──────────┼──────────┘
                       │
                   基板（Substrate）
```
- 多个裸片**平放在一个“中介层（Interposer）”上**，中介层负责横向互连。
- 裸片之间**不在垂直方向堆叠**，只是“放在同一块大板子上”，所以是 **2.5D（介于 2D 和 3D 之间）**。
- 代表：**HBM(高带宽内存) 旁边的 GPU / AI 芯片**（CoWoS）。

### 3D 封装（True 3D / 3D-IC）
```
          裸片C  ← 叠在最上
           ─────
          裸片B
           ─────
          裸片A  ← 叠在下面
        ──────────
          基板
```
- 裸片真正**一层叠一层**，层间靠 **TSV** 或 **混合键合** 垂直互连。
- 互连距离最短、集成度最高，但热和应力管理最难。
- 代表：**HBM 堆叠、NAND 3D 闪存、未来的逻辑+逻辑 3D 堆叠**。

## 3. 一张表记住区别

| 维度 | 2.5D | 3D |
| :--- | :--- | :--- |
| 裸片关系 | **平铺**在中介层上 | **垂直堆叠** |
| 横向/纵向 | 主要横向互连 | 主要纵向互连（TSV/混合键合） |
| 中介层 | 需要（Interposer） | 通常直接堆叠 |
| 密度/复杂度 | 较低 | 更高 |
| 散热/应力 | 相对可控 | 更难 |
| 典型 | CoWoS(HBM+GPU) | HBM 堆叠 / 3D NAND |

## 4. 小结

> “2.5D 是把多颗裸片平放在硅中介层上横向互连，3D 是把裸片真正垂直堆叠、靠 TSV 或混合键合纵向相连。混合键合是用 CMP 把铜焊盘和介质磨平后铜对铜直接键合，互连间距能到 10 μm 以下，是 3D 高密互连的发展方向。”
