# 02 · RDL（Redistribution Layer，重布线层）

> 一句话：把芯片上**很密、很小的 I/O 焊盘**，通过一层（或几层）金属走线，**重新布到更大、更稀疏**的焊盘上，方便后续封装和测试。

## 1. 为什么需要 RDL？

芯片制造出来，I/O 焊盘又小又密（几十微米级、间距几微米到十几微米）。
但后道的基板、电路板（PCB）的焊盘又大又稀疏（几百微米级），根本对不上。

**RDL 就是一个“转接器”**：把芯片的细密引线，拉宽、拉开，接到外部容易接的地方。

## 2. 结构示意

```
 芯片小焊盘 (fine pitch)
    ● ● ● ● ●
     │ │ │ │ │        ← 第一层金属线（细）
    └─┴─┴─┴─┴─┘
        │ │ │
     RDL 金属层（走线 + 过孔，越往外线越宽、间距越大）
        │ │ │
    ● ● ● ● ●
 大树大焊盘 (large pitch) → 连到基板/外部

```

- 最常用材料：**Cu**（导电）包一层 **Ni/Pd/Au** 防止氧化、利于键合。
- 靠 **聚酰亚胺（PI）/ 苯并环丁烯（BCB）** 这类**介质层**做绝缘与平坦化。

## 3. RDL 在哪一步？

通常用在 **WLP（晶圆级封装）/ FOWLP（扇出型晶圆级封装）**：
先临时把裸片贴到载体上，做 RDL 把 I/O 引出来，再整体切割。

> 关键词：**Fan-In（扇入）** 和 **Fan-Out（扇出）**。
> - Fan-In：I/O 全在芯片面积内（WLCSP）。
> - Fan-Out：I/O 被引到**芯片面积之外**（FOWLP），可以做更多引脚、更多层 RDL。

## 4. RDL 对性能的影响

- 走线长了反而有 **RC 延迟** → 需要平衡“布线灵活性”和“信号质量”。
- RDL 层数和线宽可调 → 决定封装成本和可用带宽。

## 5. 小结

> “RDL 是重布线层，把芯片上又小又密的 I/O 焊盘用金属走线重新分布到更大、更稀疏的焊盘上，作为芯片和基板之间的转接，支撑 fan-in / fan-out 封装；代价是走线带来的 RC 延迟，要在布线灵活性和信号质量之间权衡。”
