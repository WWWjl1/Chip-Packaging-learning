## 🔑 术语速查表（重点：能画出关系）

| 术语 | 一句话解释 | 常见搭配/场景 |
| :--- | :--- | :--- |
| **TSV** | 硅片上垂直打孔填铜，上下层直连 | 3D 堆叠、HBM |
| **RDL** | 把细密 I/O 重新布到稀疏大焊盘 | Fan-in / Fan-out, WLP, FOWLP |
| **Interposer 中介层** | 一块“转接板”，让多颗裸片平放并横向互连 | 2.5D |
| **Hybrid Bonding** | 铜对铜 + 介质对介质，无缝压接 | 高密 3D |
| **Microbump** | 传统微凸点 + 底部填充 | 传统倒装/2.5D |
| **Fan-in / Fan-out** | I/O 在芯片内 / 被引出芯片外 | WLCSP / FOWLP |
| **CoWoS** | Chip-on-Wafer-on-Substrate（台积电 2.5D 方案） | HBM + GPU/AI |
| **CMP** | 化学机械抛光，磨平表面到亚微米级 | 混合键合、TSV 制程 |

## 🎨 面试口述脚本（30 秒版）

> “先进封装是为了在摩尔定律放缓后继续提高性能。最常用的三类互连是 **TSV、RDL、混合键合**：TSV 解决‘上下层怎么直连’，RDL 解决‘细密 I/O 怎么引出来’，混合键合解决‘怎么连得更密’。形态上，**2.5D** 是把多颗裸片平放在硅中介层上横向互连（比如 CoWoS、GPU 旁边码 HBM），**3D** 是把裸片真正垂直堆叠、用 TSV 或混合键合纵向相连（比如 HBM 堆叠）。一句话：2.5D 是平铺、有中介层；3D 是堆叠、纵向互连。”
