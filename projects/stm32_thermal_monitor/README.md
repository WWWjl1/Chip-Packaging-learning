# 项目 · 基于 STM32 的芯片热管理模拟验证平台

> 把大三课设“STM32 温度采集”包装成 **芯片系统级应用验证** 的简历项目。
> 核心视角：从“采集一个温度”，升级为“**模拟多核芯片负载下的温度梯度变化**”。

## 🎯 项目一句话

> 基于 STM32 的芯片热管理模拟验证平台 —— 模拟多核芯片负载下的温度梯度变化。

## 🔄 包装思路（课设 → 简历项目）

| 原始课设 | 改造后（简历视角） |
| :--- | :--- |
| STM32 采集温度传感器 | 多路传感器阵列 + 多核负载模拟 |
| 显示一个温度值 | 采集多点温度, 拟合出**温度梯度** |
| 简单报警 | 模拟**热管理策略**（降温/降频/调度） |
| 无散热概念 | 引出**先进封装散热路径**（对应 TSV/散热通道） |

## 🧩 系统框图（建议加进项目 README/PPT）

```
  多核负载模拟 (代码生成不同的核心发热档位)
        │
  STM32 主控
    ├── 读 N 路温度传感器 (NTC/DS18B20 采样)
    ├── 计算温度梯度 / 最热核心
    ├── 触发“热管理策略”：限频 / 平衡调度 / 散热风扇档位
    └── 上位机 (串口/OLED) 显示趋势曲线
```

## 📈 与“先进封装”的连接点（面试加分）

- 把 **热管理** 与封装设计的 **散热路径 / TSV 散热通道** 联系起来。
- 强调你意识到：高性能芯片的瓶颈不只是“算力”，还有“**把热排出去**”，这正是先进封装（2.5D/3D、TSV、RDL）要解决的核心问题之一。
