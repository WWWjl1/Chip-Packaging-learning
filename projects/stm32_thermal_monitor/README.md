# 项目 · 基于 STM32 的芯片热管理模拟验证平台

> 一个基于 STM32 的芯片热管理模拟验证平台，用于模拟多核芯片负载下的温度梯度变化。

## 🎯 项目目标

> 基于 STM32 的芯片热管理模拟验证平台 —— 模拟多核芯片负载下的温度梯度变化。

## 🧩 系统框图

```
  多核负载模拟 (代码生成不同的核心发热档位)
        │
  STM32 主控
    ├── 读 N 路温度传感器 (NTC/DS18B20 采样)
    ├── 计算温度梯度 / 最热核心
    ├── 触发“热管理策略”：限频 / 平衡调度 / 散热风扇档位
    └── 上位机 (串口/OLED) 显示趋势曲线
```

## 📈 与封装热管理的关系

高性能芯片的瓶颈不只是“算力”，还有“**把热排出去**”。本项目从系统级角度观察多核负载下的温度梯度，
并把它与封装设计中的 **散热路径 / TSV 散热通道** 联系起来。
