# 仿真实验 — 芯片 I/O 热力分布

> 用 Python 模拟芯片 **Bump 引脚布局** 和 **热力分布**，画一张热力色块图。

## 🔬 建模思路

> 基于热传导方程对封装散热路径进行了简化建模。

这是一个**教学/示意级**的简化模型：用 **2D 稳态热扩散（拉普拉斯方程）** 近似芯片表面温度分布，
把每个 I/O Bump 当作一个热源，把芯片四周当作散热边界，迭代求解温度场。

## 🚀 运行

```bash
pip install -r requirements.txt
python chip_thermal_map.py
```

生成 `chip_thermal_map.png`（默认保存在当前目录）。

## 🤔 局限性 & 下一步

- 这是**定性示意**，不是真实热仿真（真实场景用 ANSYS Icepak / COMSOL / RedHawk）。
- 简化点：
  1. 假设各向同性、常数导热系数；
  2. 用有限差分近似，未建模对流/辐射；
  3. 热源位置手工设定，非真实封装。

## 📝 讲解要点

- 说明这是**教学级简化模型**，用 2D 拉普拉斯方程做有限差分迭代；实际工程会使用 ICEPAK 等商用工具。
- 重点在于理解 **物理建模** 的过程（热传导、边界条件、迭代收敛），而不是仅仅调用现成库。
